시크릿코드 E4941,

엔지니어랩 시크릿할인은 파트너스 시크릿코드 E4941을 이용해 4만원+2만원, 총 6만원 할인쿠폰 1장을 받는 혜택입니다. 신규회원과 기존회원 모두 아래 4단계로 동일하게 진행하면 됩니다.

1

회원가입 또는 로그인

엔지니어랩 공식 파트너스 페이지에서 신규 회원가입을 진행하거나, 기존 회원이면 로그인합니다.

2

시크릿코드 입력

코드 입력란에 E4941을 입력합니다.

3

쿠폰 발급 확인

마이페이지 쿠폰함에서 4만원+2만원, 총 6만원 할인쿠폰이 발급되었는지 확인합니다.

4

결제 시 쿠폰 적용

원하는 패스 상품 결제 페이지에서 발급된 쿠폰을 선택해 최종 결제 금액을 확인합니다.

코드 입력 이후 결제창에 나오는 쿠폰 적용 실제 이미지

엔지니어랩 시크릿할인 코드 이용 안내

신규 회원

신규 회원은 회원가입 시 시크릿코드 E4941을 입력하면 4만원+2만원, 총 6만원 할인 쿠폰이 즉시 지급됩니다.

기존 회원

할인 페이지에 로그인한 뒤 쿠폰 즉시받기 버튼을 클릭하면 동일한 혜택을 받으실 수 있습니다.

결제 단계

결제 페이지에서 발급된 쿠폰을 직접 선택하여 할인이 적용된 최종 금액을 확인한 뒤 결제합니다.

결제 전 체크리스트

  • ① 쿠폰 발급 확인 — 마이페이지 쿠폰함에 쿠폰이 보이지 않으면 할인 페이지에서 다시 받기를 눌러주세요.
  • ② 유효기간 확인 — 발급일로부터 30일간만 유효합니다. 쿠폰함에서 만료일을 확인해주세요.
  • ③ 적용 대상 확인 — 김상훈 교수님 필기·실기패스, 단과 상품 및 특강 등은 쿠폰 적용 제외 상품입니다.
  • ④ 중복 적용 불가 — 쿠폰은 상품 1건당 1개만 적용되며, 다른 쿠폰과 중복 적용되지 않습니다. 쿠폰이 여러 개라면 주문서에서 어떤 쿠폰이 선택됐는지 확인해주세요.

실제 화면으로 보는 신규 회원 수강 신청 방법

1

파트너스 할인 배너 확인

파트너스 링크로 접속하면 4만원+2만원, 총 6만원 할인 혜택 배너를 확인할 수 있습니다.

2

회원가입 진행

파트너스 링크로 접속한 상태에서 회원가입을 진행하면 가입과 동시에 할인쿠폰이 지급됩니다.

3

원하는 강의 선택

원하는 과정의 상품 페이지에서 수강신청을 눌러 주문 화면으로 이동합니다.

위의 사진은 예시 이미지입니다.
4

주문서에서 쿠폰적용 확인

주문서 작성 화면의 쿠폰적용란에 발급된 파트너스 할인권이 보이는지 확인합니다.

5

할인권 선택

쿠폰적용 목록에서 파트너스 4+2만원 할인권(E4941), 60,000원 할인을 선택합니다.

6

최종 결제금액 확인 후 결제

할인이 반영된 최종 결제금액을 확인한 뒤 결제를 진행합니다.
